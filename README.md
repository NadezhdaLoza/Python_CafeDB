# Python_CafeDB

Информационная система для автоматизации учета заказов и управления ассортиментом кафе-пекарни. Проект реализован в рамках курсовой работы.

## Технологии

- **Backend:** Python 3.x
- **Database:** PostgreSQL
- **Driver:** psycopg2 / SQLAlchemy (укажи то, что использовала)
- **Frontend/UI:** Vue.js
- **Modeling:** Ramus (для функциональной модели)

## Архитектура базы данных

Система построена на реляционной модели данных и включает следующие ключевые сущности:

1.  **Заказы (Товарные чеки):** Центральный документ системы, фиксирующий факт продажи.
2.  **Справочники:**
    - _Клиенты и Бонусные карты:_ Учет постоянной аудитории.
    - _Сотрудники и Должности:_ Управление персоналом.
    - _Блюда и Категории:_ Структура меню.
    - _Ингредиенты и Поставщики:_ Учет сырья и логистики закупок.
    - _Рецепты:_ Связь блюд с ингредиентами (технологические карты).

## Установка и запуск

### Предварительные требования

- Установленный Python 3.8+
- Запущенный локальный сервер PostgreSQL
- Созданная база данных `cafe_db` (или иное имя из твоей работы)

### Шаги запуска

1.  Клонируйте репозиторий:

    ```bash
    git clone [URL_РЕПОЗИТОРИЯ]
    cd cafe-bakery-db
    ```

2.  Установите зависимости:

    ```bash
    pip install -r requirements.txt
    ```

    _(Если файла requirements.txt нет, создай его командой `pip freeze > requirements.txt` перед коммитом)_

3.  Настройте подключение к БД:
    Отредактируйте файл конфигурации (укажи имя своего конфига, например `config.py`), указав данные пользователя PostgreSQL.

4.  Инициализируйте базу данных:
    Выполните SQL-скрипт `init_db.sql` (если он есть) или запустите основной скрипт приложения для создания таблиц.

5.  Запуск приложения:
    ```bash
    python main.py
    ```

## Структура проекта

- `models/` — описание структур данных и связей
- `utils/` — утилиты для подключения к БД
- `forms/` — логика пользовательского интерфейса (если применимо)
- `sql/` — скрипты создания таблиц и тестовых данных
